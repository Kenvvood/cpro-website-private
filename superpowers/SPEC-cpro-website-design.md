## 一、项目概述

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 城诺科技 |
| 英文名称 | CPro Trading |
| 业务定位 | 专业MQL量化解决方案提供商 |
| 核心产品 | MT4/MT5 智能EA、技术指标、脚本工具 |

### 1.2 网站目标

1. **品牌展示** — 树立专业、可靠的量化交易工具品牌形象
2. **内容营销** — 通过教程、案例、策略分享吸引目标客户
3. **会员引流** — 通过免费工具下载获取潜在客户联系方式（手机号+微信号）

### 1.3 目标客户

- 外汇/黄金交易小白
- 想要扩展外汇黄金赛道的公司/工作室
- 网赚项目从业者

## 二、设计风格

### 2.1 整体风格

| 维度 | 描述 |
|------|------|
| **视觉风格** | 深色科技风 + 荧光点缀 |
| **设计语言** | 现代金融科技感、专业高端 |
| **布局方式** | F型布局（符合用户阅读习惯）|

### 2.2 色彩系统

#### 主色调

| 颜色名称 | 色值 | 用途 |
|---------|------|------|
| 主色（Tiffany Blue） | `#00E5DD` | CTA按钮、强调文字、hover状态 |
| 辅色（电紫） | `#7B61FF` | 渐变搭配、辅助点缀 |
| 深蓝 | `#00C4CC` | 按钮渐变搭配 |

#### 背景色

| 颜色名称 | 色值 | 用途 |
|---------|------|------|
| 主背景 | `#0a0a0f` | 页面背景 |
| 次背景 | `#0f0f16` | 卡片背景、统计条 |
| 卡片背景 | `#14141c` | 内容卡片 |
| 悬浮背景 | `#1a1a24` | hover状态 |

#### 文字色

| 颜色名称 | 色值 | 用途 |
|---------|------|------|
| 主文字 | `#ffffff` | 标题、重要文字 |
| 次文字 | `#b0b0c0` | 正文、描述 |
| 弱文字 | `#707080` | 标签、元信息 |

#### 边框色

| 颜色名称 | 色值 | 用途 |
|---------|------|------|
| 默认边框 | `rgba(255,255,255,0.08)` | 卡片边框 |
| 强调边框 | `rgba(0,229,221,0.35)` | hover、active状态 |

### 2.3 荧光效果

| 效果类型 | 实现方式 |
|---------|---------|
| **发光阴影** | `box-shadow: 0 0 30px rgba(0,229,221,0.5)` |
| **强发光** | `box-shadow: 0 0 60px rgba(0,229,221,0.6), 0 0 120px rgba(0,229,221,0.3)` |
| **文字发光** | `text-shadow: 0 0 40px rgba(0,229,221,0.5)` |
| **图标光晕** | `filter: drop-shadow(0 0 8px rgba(0,229,221,0.5))` |
| **渐变光线** | `linear-gradient(90deg, transparent, var(--accent), transparent)` |

### 2.4 背景装饰

- **渐变光球**：右上角放射性渐变光晕（青色+紫色）
- **网格线**：全屏点阵网格装饰，增强科技感

## 三、页面结构

### 3.1 F型布局架构

```
┌─────────────────────────────────────────────────────────────┐
│  Logo    首页 / 产品中心 / 内容中心 / 关于我们    登录  注册 │  ← 顶部导航栏
├────────┬────────────────────────────────────────────────────┤
│        │                                                    │
│  侧边栏  │   Hero区（标题+CTA左对齐）                        │  ← 左侧垂直线
│  产品   │                                                    │
│  分类   │   数据统计条（4列）                                │
│        │                                                    │
│  内容   │   产品卡片（3列）                                  │  ← F横线
│  分类   │                                                    │
│        │   最新内容列表  │  快速链接                        │  ← F下横线
│  注册   │                                                    │
│  CTA   │                                                    │
└────────┴────────────────────────────────────────────────────┘
```

### 3.2 页面模块

| 模块 | 描述 | 位置 |
|------|------|------|
| **顶部导航栏** | Logo、主导航、登录/注册按钮 | 全站固定 |
| **左侧边栏** | 产品分类、内容分类、注册CTA | 左侧固定 |
| **Hero区** | 品牌标语、核心CTA按钮 | 主内容区顶部 |
| **数据统计条** | 用户数、产品数、稳定性、技术支持 | 主内容区 |
| **产品展示** | 热门产品卡片（EA/指标/脚本）| 主内容区 |
| **内容列表** | 最新教程、案例、策略分享 | 主内容区 |
| **快速链接** | 下载专区、技术支持、社群入口 | 右侧边栏 |
| **CTA区块** | 底部注册引导 | 主内容区底部 |
| **Footer** | 版权信息、链接 | 全站底部 |

## 八、技术架构建议

### 8.1 推荐技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端框架 | Next.js / Nuxt | SSR/SEO友好 |
| UI组件 | Tailwind + Shadcn | 快速开发 |
| 后端框架 | Next.js API / Nuxt Server | 轻量级API |
| 数据库 | PostgreSQL | 关系型数据 |
| ORM | Prisma / Drizzle | 类型安全 |
| 认证 | NextAuth / 短信SDK | 登录+注册 |
| 文件存储 | OSS / S3 | 产品文件存储 |
| 短信服务 | 阿里云 / 腾讯云 | 短信验证 |

### 8.2 目录结构建议

```
cpro-website/
├── src/
│   ├── app/                 # Next.js App Router
│   │   ├── (marketing)/     # 营销页面
│   │   │   ├── page.tsx    # 首页
│   │   │   ├── products/    # 产品中心
│   │   │   ├── content/    # 内容中心
│   │   │   └── about/     # 关于我们
│   │   ├── (member)/       # 会员页面
│   │   │   ├── login/      # 登录
│   │   │   ├── register/   # 注册
│   │   │   ├── dashboard/  # 会员中心
│   │   │   └── downloads/   # 下载专区
│   │   └── api/            # API路由
│   ├── components/          # 组件
│   │   ├── ui/             # Shadcn组件
│   │   ├── layout/         # 布局组件
│   │   └── features/       # 功能组件
│   ├── lib/                 # 工具函数
│   └── styles/              # 全局样式
├── prisma/
│   └── schema.prisma        # 数据库模型
└── public/
    └── downloads/          # 下载文件（私有）
```
